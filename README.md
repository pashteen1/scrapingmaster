# ScrapingMaster – Luxury Edition

Premium black + gold website for professional web scraping services.

## Features
- Bold agency-style homepage: “The Scraping Agency That Actually Delivers”
- 46 services with search/filter
- Articles section
- WhatsApp + Email + LinkedIn contact
- Fully responsive
- Ready for GitHub + Vercel auto-deploy

## How to deploy (GitHub method – recommended)

1. Create a new GitHub repository named `scrapingmaster`
2. Upload **all files and folders** from this package (do not put them inside another folder)
3. Go to vercel.com → New Project → Import the GitHub repo → Deploy

After that, every time you edit a file on GitHub and click Commit, the live site updates automatically.

## Daily updates
- Add/edit articles → edit files in the project or add new HTML pages
- Change services → edit `js/services-data.js` or contact me for bulk updates
- Update contact info → edit the footer and contact.html
